# 🐉 AzerothCore PHP Pages

Repositorio donde subiré varias páginas en **PHP** para servidores **AzerothCore** (World of Warcraft 3.3.5a).

Aquí encontrarás scripts, módulos web y utilidades para gestionar tu servidor desde el navegador: registros, panel de usuario, rankings, tienda, etc.

## ⚙️ Requisitos

Antes de usar estas páginas, asegúrate de tener:

- **PHP** 7.4 o superior (recomendado 8.x)
- **MySQL / MariaDB** (base de datos de AzerothCore: `acore_auth`, `acore_characters`, `acore_world`)
- Servidor web: **Apache** o **Nginx**
- Extensión PHP: `mysqli` o `PDO_MySQL`
- Servidor **AzerothCore** funcionando
